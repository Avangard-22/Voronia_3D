# Stage 7.1 — Galaxy Interaction

## Реализовано

- Выбор обнаруженных систем в 3D-сцене больше не вызывает перелёт автоматически.
- Выбранный узел получает кольцо выделения, камера плавно фокусируется на нём.
- Для выбранной открытой системы строится подсвеченный маршрут из актуального `GameSnapshot.galaxy.routes`.
- В карточке системы показываются имя, биом, геометрия, рукав, сектор, координаты, состояние и параметры доступного маршрута.
- Перелёт запускается отдельной кнопкой и проходит через `Game.dispatch('travelToPlanet', ...)`, поэтому доменные проверки и списание энергии не обходятся.
- После успешного перелёта отображается маркер корабля, проходящий по всем сегментам маршрута.
- Неизвестные сигналы нельзя выбрать; вспомогательные функции фильтруют скрытые и отсутствующие узлы из маршрута.
- Панель адаптирована для узких экранов.

## Новые модули и тесты

- `src/renderer/galaxyInteraction.ts` — безопасный выбор узла, очистка пути и интерполяция положения корабля.
- `tests/stage7_1_galaxy_interaction.test.ts` — три проверки выбора/приватности скрытых узлов, фильтрации пути и интерполяции.

## Проверки, фактически выполненные

- Строгая компиляция `galaxyModel.ts` и `galaxyInteraction.ts` — пройдена.
- Node smoke-тест трёх функций интерактивности — пройден (`stage7.1 smoke: OK`).
- `npm ci --ignore-scripts --no-audit --no-fund --prefer-offline` — завершился по тайм-ауту; частичный `node_modules` не используется в архиве.
- Полный TypeScript приложения, Vitest, production build и браузерный WebGL smoke-test не выполнены.

## Ограничения

- Анимация корабля — визуализация уже подтверждённого доменного перелёта; она не является самостоятельной симуляцией физики.
- В карточке показываются только данные, доступные в текущем snapshot. Неизвестные планеты не раскрывают скрытые характеристики.
- Полноценная 3D-камера полёта и детальные модели отдельных звёздных систем относятся к последующим этапам.
