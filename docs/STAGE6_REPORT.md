# Stage 6.0 — SONAR SYSTEM

**Статус:** частично завершён; первая вертикаль сонарного открытия подключена к игровому циклу.

## Реализовано

1. **Сонарная мини-игра.** Три последовательных сигнала. Игрок останавливает движущийся маркер; оценка каждого раунда: `clamp(1 - abs(position) * 1.4, 0, 1)`. Число раундов, период и пороги наград читаются из `registry.sonar`.
2. **Открытие Криос-9.** Требуется активный Феррум, полное исследование всех клеток Феррума и `hintEnergy` (1500 энергии по текущему реестру). Оплата проводится атомарно через ledger. После успешного сканирования Криос-9 попадает в `unlockedPlanets`, runtime создаётся, узел графа получает `discovered: true`.
3. **Бонус добычи.** Средняя точность ≥50%, ≥70%, ≥90% даёт множитель `rewardOk`, `rewardGood`, `rewardPerfect` соответственно на `rewardHours` (24 часа). Множитель подключён к существующему `IncomeService` через `scanBonus` для Криос-9. При точности ниже 50% планета открывается без бонуса.
4. **Сохранение.** `sonarCharges` продолжает сохраняться; добавлена секция `sonarBonus` с планетой, множителем, временем окончания и точностью. Просроченный бонус не восстанавливается.
5. **Превью следующего мира.** Генератор запускает `runDiscovery` на изолированной копии текущего графа и планет. Seed превью передаётся в фактическую команду открытия. Поэтому имя, биом, геометрия и список ресурсов в превью совпадают с созданным миром. Превью кэшируется и пересчитывается после открытия мира.
6. **UI.** Добавлены карточка сонарной станции, сигнатуры Криос-9, условия запуска, интерактивная полоса сигнала, оценка каждого импульса, итог и превью следующего процедурного мира.

## Границы этапа / остаток

- Расход сонарных зарядов, reroll/пересборка планеты, история повторных попыток и лимит `rerollMax` не подключены.
- Превью реализовано через повтор полного discovery pipeline на копии графа; это обеспечивает совпадение результата, но не является прямым портом исходной функции Zn.
- Существующий generic `discoverPlanet` API сохранён для совместимости Stage 5; UI показывает кнопку следующего мира только после открытия Криос-9.
- TV-33 остаётся PARTIAL до реализации полного цикла повторного сканирования/расхода зарядов.
