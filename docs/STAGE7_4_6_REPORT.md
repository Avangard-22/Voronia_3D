# Stage 7.4.6 — System Exploration Completion & Data Persistence

## Реализация

- Сохранение продолжает использовать `orbitalExploration[hostPlanetId]` с `scannedBodyIds` и `activatedBodies`; формат сейва не менялся.
- Валидатор сейва проверяет, что родительская планета открыта.
- Идентификаторы сканируемых и активированных тел должны принадлежать указанному host (`body:<hostId>:<index>`).
- Список сканирований не может содержать дубликаты.
- Активация допустима только для ранее просканированного тела.
- Целевая планета активации должна быть открыта и иметь `DiscoverySpec`, необходимый для детерминированного восстановления runtime.
- Одна планета не может быть привязана к нескольким орбитальным телам одной системы.
- Добавлены тесты восстановления активной орбитальной планеты, сохранения связей после round-trip и отклонения неконсистентных данных.

## Совместимость

Версия схемы сохранения остаётся `2`. Новые обязательные поля не добавлялись. Старые сейвы без `orbitalExploration` по-прежнему допустимы; корректные сейвы 7.4.1–7.4.5 сохраняют прежнюю структуру.

## Проверка

Архитектурный чек и целостность архивов выполняются отдельно при сборке пакета. Полный TypeScript/Vitest/build и браузер/WebGL не считаются пройденными, если среда не содержит установленных зависимостей и браузерный запуск не выполнялся.
