# ADR-010: Системы вне ТЗ §4 переносятся полностью

**Статус:** ПРИНЯТО (второй пакет владельца)

## Решение

weekly-циклы, 125 достижений, лор/финал, вселенные «Раскола» (_shared/_u<N>), ghost, cinematic, sonar, charge, boss-рейды — переносятся в 2.0 полностью (Q2 закрыт). Приоритет — ядро Этапов 1–6; перечисленное — на своих этапах (реестр-секции: weekly/social/cinematic/sonar/charge/boss/ghost/echo/shards/premium — уже в registry.json).
