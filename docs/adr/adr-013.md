# ADR-013: Экономика: атомарные транзакции ledger; тик; журнал; scope

**Статус:** ПРИНЯТО

## Решение

Баланс меняется ТОЛЬКО через ResourceLedger (ворота ТЗ §15). Транзакция {id, reason, scope, delta, gameMs} атомарна: нехватка ЛЮБОГО ресурса → отказ ЦЕЛИКОМ (GS-05). Действия = одна агрегированная транзакция (скан: −charge +награды; апгрейд: −стоимости +levelRewards; доход тика: одна транзакция на scope за тик). Производство/с отделено от запасов; резервы жил, cooldown, уровни — доменное состояние клетки (не ledger). Активная планета ↔ scope 'global' (parity 1.x); planet:* scope — Этап 9 (неактивные планеты/транспорт). Журнал транзакций — in-memory cap 200, НЕ персистится (восстановление не требуется; аудит — через bus history).
