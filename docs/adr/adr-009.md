# ADR-009: Боевой раздел: источник истины — реестр v0.0.41

**Статус:** ПРИНЯТО (второй пакет владельца)

## Решение

Числа ТЗ §9 SUPERSEDED: реестр `boss` v0.0.41 содержит strike-модель (удар 6±3с, лимит 30с, комбо ×0.1…×5), тиры стражей (sentinel/guardian/overlord, CD overlord 3ч), потери 3–8 клеток (не 25%), восстановление 15 мин / 1800⚡ (не 30 мин / 250🔬+25💎). Боевой домен (Этап 8/10) строится ПО РЕЕСТРУ.
