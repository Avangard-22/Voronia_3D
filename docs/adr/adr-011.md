# ADR-011: Баланс: только версионированные наборы (registryView + baseline)

**Статус:** ПРИНЯТО

## Решение

Конфигурация — versioned-набор `v0.0.41`: (1) `registry.json` — копия window.VORONIA_BALANCE после override-v41 (37 секций), типизированный RegistryView с fail-fast валидатором (список проблемных путей); (2) `baseline.json` — source-only константы (кривая g0, Vr-таблицы, формулы жил/аномалий, таблицы рукавов) с `_provenance`. Никаких «выдуманных» формул: каждое число — извлечение из baseline (offset) или реестр. Смена баланса = новый versioned-набор + миграция сейвов.
