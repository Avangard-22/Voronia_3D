# ADR-014: Рукава галактики и цепочки модификаторов

**Статус:** ПРИНЯТО

## Решение

Модификаторы дохода/цен — типизированные контексты с ИМЕНОВАННЫМИ множителями (порядок из ce()/ln()/zn()/C1()): deep/charge/scanBonus/sleep/biome/perk/arm/compound/warehouse/dust/meta/tech/role/echo/seal/event — хуки поздних этапов входят множителем 1 и заменяются своими доменами. Таблицы рукавов (core/inter/forge/frost/life/void — Df/Za/Lr) и biomeMults (Xc) — в baseline.json (fixtures/galaxy_arms_full.json). Подтверждено runtime-аудитом: ×0.9 скана = «ЯДРО», ×1.2 апгрейда = «Мёрзлый», ×1.15 железа = «Каменистый», ×6 дохода = compound (кап Fa).
