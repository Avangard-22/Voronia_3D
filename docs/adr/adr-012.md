# ADR-012: Слои: contracts ← config ← домены ← core ← ui; порты; Game — единственный сборщик

**Статус:** ПРИНЯТО

## Решение

Матрица слоёв: contracts(0) не импортирует ничего; config(1) ← contracts; домены(2: economy/planets/progression/persistence + заглушки renderer/audio/galaxy/logistics/combat/crafting) ← contracts/config и ТОЛЬКО через порты (EventPort/LedgerPort/TechPort/ScanPricingPort/RngPort/StoragePort/LogPort/TickListener) — домен↛домен и домен↛core запрещены; core(3: Game-fасад, EventBus, GameClock, Rng, Logger) — единственный DI-сборщик; ui(4) — рендер из снапшотов, команды через dispatch; main.ts — composition root. Контроль: `tools/check_arch.mjs` (слои, циклы, границы) в CI.
