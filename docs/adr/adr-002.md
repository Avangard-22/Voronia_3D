# ADR-002: Дистрибуция: модульный dist + single-file target ≤ 6 МБ

**Статус:** ПРИНЯТО (Q3 владельца: бюджет ≤6 МБ)

## Решение

Два артефакта сборки: (1) обычный vite-dist (модульный, sourcemaps), (2) самодостаточный single-file HTML (vite-plugin-singlefile) — наследие монолита, удобство распространения. Бюджет single-file: ≤6 МБ, гейт `npm run check:size` в CI. Текущий размер: ~0.1 МБ (срез Этапа 2).
