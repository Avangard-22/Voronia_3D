# ADR-018 — Этап 8.1: транзит через неоткрытые системы, контракт маршрута и ремонт CI-контура

**Дата:** 2026-11-03 · **Статус:** superseded in part by Phase 10.1.4 · **Контекст:** красный CI (`npm run build` → `tsc`), 13 падающих тестов из 349, и воспроизводимый баг связности галактики: открытая планета недостижима, `validateIntegrity()` помечает легальное состояние как `unreachable-unlocked-planet`. Аудит: `docs/STAGE8_1_CI_REPAIR_REPORT.md`.

## Решения

1. **Historical galaxy-route behavior:** `travelToPlanet` may route through undiscovered transit nodes and stops only at unlocked runtime planets. This remains an internal compatibility API; the playable map is restricted to one planetary system.

2. **Транзит платный: надбавка вместо запрета.** `ROUTE_POLICY.lockedTransitMultiplier = 1.5` для ребра, один из концов которого нанесён на карту (`discovered`), но не открыт; `ROUTE_POLICY.blindTransitMultiplier = 2.5` — для ребра с неизученным узлом. Dijkstra предпочитает полностью открытые маршруты, а слепой пролёт остаётся аварийным вариантом. Надбавка применяется к каждому физическому ребру (`ceil(legEnergy × multiplier)`), сумма сегмента = стоимость одного «прыжка» в UI. Значения — единственная точка балансировки (ТЗ §15: баланс меняется в одном месте).

3. **Контракт Этапа 6.6 сохранён за флагом.** `findGalaxyRoute(..., { allowTransit: false })` воспроизводит прежнее поведение («транзит только через открытые и изученные узлы»). Это позволяет тестам проверять обе семантики и даёт владельцу переключатель, если транзит окажется нежелательным для баланса.

4. **Валидация и маршрутизация используют один граф.** `buildChartedComponents(graph)` (компоненты связности по всем рёбрам) вынесена в `galaxy/routes.ts` и переиспользуется в `galaxy/validation.ts`: проверка `unreachable-unlocked-planet` и `route-uses-nonedge` больше не могут разойтись с реальными возможностями роутера. `route-uses-nonedge` теперь означает «остановки не связаны картой переходов», а не «нет прямого ребра» — прямое следствие сжатия пути (решение 1).

5. **Superseded by Phase 10.1.4:** `setActivePlanet` is once again a free V1-style switch between unlocked runtimes and swaps planet-local storage. `travelToPlanet` remains the distinct paid route command.

6. **Классификация аномалий: геометрия важнее биома.** `kindFor()` в `galaxy/anomalies.ts` проверял `/void|пустот|living/` по конкатенации «geometry + biome» первым, поэтому мир «rift anomaly» в биоме «void» получал вид `living-void` (20000⚡/10000🔬, 8 💫) вместо tier-1 `rift` (2500⚡/500🔬, 2 💫). Новый порядок: `rift → singularity → echo` по `geometryName`, затем `living-void` по обоим полям, затем `singularity/echo` по биому, затем порядковый номер цепочки. Стоимость цепочки экспедиций (Stage 6.5, GS-16) снова соответствует реестру.

7. **`@types/three` — обязательная dev-зависимость.** `three@0.170.0` не поставляет `.d.ts`; без типов `tsc -p tsconfig.app.json` падал (TS7016 + implicit-any), а typed-правила eslint давали 1089 ошибок. Добавлен `@types/three@^0.170.0`: ошибки tsc 30 → 12, eslint 1089 → 39, далее добиты вручную до нуля.

8. **Пустых стопок в логистике не существует.** `LogisticsService.unload/withdraw` нормализуют груз и депо через `pruneEmpty` (канон уже применялся в `hydrate`): `snapshot().logistics.cargo.iron === undefined`, а не `0`. Устраняет расхождение контракта снапшота и экономит поля сейва.

9. **Рендерер не рисует петли.** `buildGalaxyRenderData` отбрасывает рёбра `a === b` (валидация графа уже считает `self-edge` ошибкой — рендер не должен быть слабее валидатора).

10. **Контракт меша Stage 8.0.x зафиксирован тестами, а не «магическим числом».** Тесселяция сторон (`segments = clamp(ceil(угол/0.12), 1, 12)`, 9 треугольников на сегмент с каждой из двух сторон ребра) выражена в `tests/stage5_renderer.test.ts` через `tessellatedEdgeSegmentCount`/`featureTriangleCount`/`sharedEdgeCount` + golden-число для детерминированной сборки Феррума (4023). Неисследованные клетки больше не красятся из per-type `unexplored`-палитры (Stage 8.0.2: это раскрывало тип клетки) — тест проверяет единый нейтральный тон для revealed и более тёмный для hidden.

## Альтернативы (отклонены)

- **Вешать новый мир только на открытый узел** (правка `linkDiscoveredNode`): меняет детерминированную топологию графа и ломает фикстуры/parity Этапа 3 (`fixtures/planetgen_*`, аудит §discover «узел x53.0765/y0.232/z21.881, ребро → krios»). Транзит решает ту же проблему без изменения генерации.
- **Авто-`unlock` якорного узла:** открывает Криос-9 в обход сонар-механики (TV-33, Stage 6.0) и ломает `discovered ⟺ unlocked`-инвариант стартового мира.
- **Помечать транзитные узлы `discovered`:** раскрытие метаданных (имя/биом/класс сигнала) в обход прогрессии; галактическая карта уже показывает неизвестные сигналы без этого флага.
- **Unify all switching behind paid routes:** rejected for the V1 gameplay loop; explicit local planet switching and paid route travel are now separate commands.
- **Чинить только CI, тесты оставить красными:** 4 из 13 падений — не устаревшие ожидания, а реальный баг связности с повреждением сейва.
