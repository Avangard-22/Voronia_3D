# ADR-001: Платформа: паритет desktop + mobile

**Статус:** ПРИНЯТО (владелец, 2026-10-23)

## Решение

Игра поддерживает desktop и mobile с паритетом функциональности; адаптивность — media-query (в 1.x есть), прогон на устройствах — Этап 12. UI-срезы этапов собираются mobile-first (тап-цели ≥44px, HUD-колонки сворачиваются).
