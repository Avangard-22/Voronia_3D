# ADR-003: Baseline миграции и parity: v0.0.41 (монолит, не изменять)

**Статус:** ПРИНЯТО

## Решение

`Voronia_2.5D_Hybrid_v0.0.41_PROD.html` (2 949 932 Б, Three.js r170, save schema 39, ключ cosmicClickerV19) — единственный baseline. Файл не изменяется (ТЗ §19). Все числа 2.0 извлекаются из него runtime-аудитом (harness boot + __INT), а не переносятся из ТЗ «на глаз». Dual-track: hotfix-ветка 0.0.4x живёт до G5 версии 2.0.
