# Stage 9.5 — Legacy UI Fidelity Audit

**Дата:** 2026-11-04  
**Сравниваемые версии:** оригинал `v0.0.41.0` (`https://avangard-22.github.io/Voronia/`) и `Voronia_3D 2.0.0-stage9.4.7`.  
**Тип этапа:** аудит соответствия интерфейса; игровые правила и состояние не менялись.

## Итог

**Stage 9.4 восстановил общий каркас, но не достиг функционального или визуального паритета с v0.0.41.0.** Четыре нижних раздела и прямое взаимодействие с 3D-клетками присутствуют. При этом часть характерных элементов первой версии отсутствует, упрощена или заменена временными представлениями.

Нельзя объявлять Legacy UI Restoration полностью завершённым по одному факту наличия HUD, навигации и нескольких модальных окон.

## Конкретные расхождения, подтверждённые исходниками

1. `src/ui/app.ts`: `CELL_ICONS` и `RESOURCE_META` отображают glyph/emoji; оригинальный SVG-набор v0.0.41.0 в архиве отсутствует. Это не визуальный паритет.
2. `src/ui/app.ts`: панель клетки предоставляет отдельные кнопки Scan/Upgrade/действия. Двухтактное управление «первый тап — выделить, второй тап — действие» из подсказки оригинала отдельно не подтверждено.
3. `src/main.ts`: титульный экран содержит Continue/Start и New Game. В нём нет доступа к настройкам/вселенной и нет сценария share-save.
4. `src/ui/app.ts`: верхние быстрые действия первой версии не представлены отдельной компактной полосой. Наличие отдельных доменных экранов не равно восстановлению исходного quick-action layout.
5. `src/ui/app.ts`: системные окна верхней панели ограничены Save, Journal, Settings и About. Это существенно меньше набора тематических окон v0.0.41.0.
6. `docs/TO_VERIFY.md`: офлайн-доход, роли планет и отдельные offline-поведения остаются OPEN. Их нельзя объявлять восстановленными элементами интерфейса.

## Приоритет исправлений после аудита

### P0 — до визуального утверждения Legacy UI
- Получить и подключить исходный `VORONIA_ICONS` SVG pack из v0.0.41.0 (без перерисовки эмодзи как замены).
- Снять реальные скриншоты оригинала и 2.0 в одинаковых viewport: 390×844, 412×915, 1366×768.
- Сверить размеры/позиции HUD, нижней навигации, панели клетки и quick-action controls.

### P1 — функциональная parity
- Восстановить quick-action strip: sonar, galaxy map, fullscreen, combat/event actions с проверкой доступности.
- Вернуть подробный экран «Склад и добыча» с глобальным/локальным запасом, доставками, производством и специализацией только для реализованных механик.
- Проверить двухтактное касание клетки и pinch zoom на Android.
- Расширить титульный экран: Settings и Universe access только после подключения реальных сценариев.

### P2 — тематические окна
- Составить отдельные parity карточки для науки, реактора/материи, Стража, достижений, статистики, Эссенции, престижа, осколков и настроек графики.
- Каждое окно связывать с действующей командой/снапшотом; не добавлять декоративные кнопки без обработчика.

## Ограничения аудита

- Оригинальная страница была проверена в опубликованном состоянии через доступное DOM/text representation. Полный оригинальный HTML/CSS/SVG asset bundle в текущем архиве отсутствует.
- Поэтому pixel-perfect сравнение, точные CSS breakpoints и визуальная регрессия по скриншотам не выполнялись.
- `npm ci` в среде аудита завершился по тайм-ауту; `npm run ci`, браузерный запуск и Android/WebGL QA не выполнены.
- Этот отчёт фиксирует подтверждённые расхождения по доступному DOM и исходникам, а не утверждает прохождение визуальной приёмки.

## Решение

**Stage 9.5: AUDIT COMPLETE / UI FIDELITY: NOT ACCEPTED.**  
Stage 9.4 можно считать реализованным структурно, но нельзя считать завершённым восстановлением интерфейса первой версии. Следующий этап должен устранять P0/P1, начиная с оригинальных SVG-иконок и реального screenshot baseline.
