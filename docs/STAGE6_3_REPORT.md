# Stage 6.3 — Galaxy Depth

## Цель этапа
Продолжить развитие доменной логики галактики до полноценного 3D-рендеринга. Карта должна отображать вычисляемое состояние мира, а не иметь собственную независимую логику.

## Реализовано

### 1. Сектора галактики
- Введены четыре фиксированных радиальных сектора: Ядро (<12), Внутренний (12–35), Средний (35–65), Внешний рубеж (>=65).
- Сектор рассчитывается из мировых координат XZ и не зависит от состава текущего графа, поэтому открытие новых миров не перемещает старые узлы между секторами.
- Сектор показывается для сонарного preview и каждого узла в snapshot.

### 2. Состояние исследования
- Snapshot сообщает число открытых миров по каждому сектору.
- Snapshot сообщает список уникальных галактических рукавов, в которых уже есть обнаруженные миры.
- Эти данные вычисляются из `world.graph`, отдельная копия прогресса не создаётся и не требует отдельного сейва.

### 3. Аномальный барьер
Аномальные сигнатуры нельзя открыть только оплатой энергии и зарядов. Требуются одновременно:
- не менее 3 обнаруженных миров;
- не менее 2 разных рукавов;
- не менее 1500 исследований.

Проверка выполняется на доменном уровне в `Game.discoverWorld`; UI лишь показывает условия и блокирует кнопку для удобства. Подмена состояния интерфейса не позволяет обойти проверку.

### 4. Интерфейс
- Сектор будущего мира отображается в сонарном preview.
- Для карты добавлена сводка распределения миров по секторам и числу исследованных рукавов.
- Карточки обнаруженных планет показывают сектор.
- При аномальном барьере показываются все текущие/требуемые значения.

## Ограничения
- Пороги аномального доступа (3 мира, 2 рукава, 1500 исследований) являются балансным решением Stage 6.3 и должны быть проверены в полном игровом прогоне.
- Сектора сейчас радиальные, не отдельные процедурно генерируемые области с собственными событиями.
- Полноценный 3D-рендеринг галактики не входит в Stage 6.3.
