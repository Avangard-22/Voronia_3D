# Stage 8.0.5 — Planet Surface Topology & Adaptive Tessellation

## Цель

Усилить топологическую согласованность поверхности планеты, не превращая поли-сетку Voronia в регулярную hex-сетку. Исходный контур каждой ячейки по-прежнему определяется `cell.poly`.

## Реализация

- Добавлен предварительный проход, собирающий канонические рёбра полигонов независимо от направления обхода.
- Для каждого ребра вычисляется сегментация по угловой длине: ориентир 0.12 радиана на сегмент, диапазон 1–12 сегментов.
- Промежуточные точки вычисляются сферической интерполяцией (slerp) и повторно используются обеими соседними ячейками.
- Концы рёбер используют общие вершины из единого vertex map; это сохраняет согласованность в местах схождения нескольких рёбер.
- Внутренние кольца рельефа строятся отдельно для каждой ячейки. Таким образом, адаптивная сегментация общих границ не уничтожает индивидуальную морфологию клеток.
- `PlanetMeshData` расширен диагностикой `sharedEdgeCount`, `tessellatedEdgeSegmentCount`, `tJunctionCount`.
- Добавлены тесты на общие рёбра, конечность координат, сохранение полигональных границ и соответствие `faceCellIds` числу граней.

## Ограничения

- Это адаптивная сегментация рёбер по угловой длине, а не полноценная адаптивная триангуляция с экранно-пространственным LOD.
- Переходы высот на общей границе используют единый seam-профиль, но плавное смешивание материалов/нормалей между клетками ещё не добавлено.
- Диагностика `tJunctionCount` отражает инвариант построителя: общие рёбра используют одну каноническую последовательность точек. Она не является независимым пост-фактум валидатором произвольного внешнего меша.
- Браузер/WebGL проверка отложена по запросу пользователя.

## Проверки

- `node tools/check_arch.mjs` — выполнен отдельно после изменений.
- ZIP/TAR целостность — проверяется при упаковке.
- TypeScript/Vitest — не запускались, так как `node_modules` отсутствует в рабочем окружении.
