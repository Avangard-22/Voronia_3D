# Stage 8.0.1 — Planet Surface Interaction Core

## Scope

Подключено базовое прямое взаимодействие с клетками на 3D-поверхности к существующей доменной модели. Экономика и правила открытия клеток не дублируются в рендерере.

## Реализовано

- Mesh builder получает `revealed` вместе с `explored` и уровнями из `PlanetRuntime`.
- Для каждой клетки формируется `cellSelectable`: доступ к выбору разрешён только для `revealed ∪ explored`.
- Маркеры скрытых клеток не отображаются; типы скрытых клеток не раскрываются их маркерами.
- Raycast по поверхности сопоставляет `faceIndex → cellId`, затем проверяет `cellSelectable` до вызова обработчика выбора.
- Выбор открытой клетки передаётся в существующий HUD. Действия сканирования и улучшения продолжают выполняться исключительно через `Game.dispatch` (`scanCell`, `upgradeCell`), поэтому доменные проверки и списание ресурсов остаются в Game.
- Добавлен тест соответствия selectable-маски набору открытых клеток.

## Границы подэтапа

Это interaction core: выбор, отображение доступности и подключение к уже существующим командам. Полная визуальная обратная связь уровней, анимация сканирования, контекстные панели непосредственно поверх сферы и расширенная тактильная оптимизация остаются следующими задачами Stage 8.0.x.

## Проверка

Архитектурный скрипт и целостность архивов запускаются при упаковке. Полный TypeScript/Vitest/browser/WebGL прогон не заявляется без установленных зависимостей и браузерной приёмки.
