# Stage 6.2 — Galaxy Exploration

## Реализовано

- Добавлен доменный модуль `galaxy/exploration.ts` с классификацией сигналов: аномальный, энергетический, криогенный, ресурсный и неизвестный.
- Классификация использует биом, геометрию и ресурсные маркеры предварительного просмотра; для уже созданных узлов использует биом/геометрию/частоту.
- Галактические координаты XZ преобразуются в нормализованные координаты карты 0..1000; нулевой диапазон обрабатывается без NaN.
- Снимок игры сообщает число обнаруженных узлов и прогресс ближайшего галактического рубежа (2, 3, 5, 8, 12, 18, 25, 35, 50 обнаруженных миров).
- UI получил карту со связями только между обнаруженными узлами, скрытые узлы отображаются как неизвестные, активная планета выделяется отдельно.
- Добавлен журнал обнаруженных миров с биомом, геометрией, рукавом и классом сигнала.
- В карточке будущего сонарного сигнала отображается его классификация. Открытие и перелёт по-прежнему выполняются через существующие команды Game.

## Ограничения / честный статус

- На этом этапе пока существует одна текущая сигнатура preview, а не пул нескольких сигналов для выбора. UI не предлагает фиктивный выбор.
- Классы сигналов — эвристическая классификация существующих полей генератора, не отдельная генераторная таблица баланса.
- Галактические рубежи являются индикаторами прогресса; дополнительные награды за них не вводились, чтобы не создавать несогласованные изменения экономики.
- Не добавлялась система дальних экспедиций/маршрутов: перелёт доступен только к уже открытым планетам.
