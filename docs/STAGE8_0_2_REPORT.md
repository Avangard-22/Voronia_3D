# Stage 8.0.2 — Cell Visual States & Surface Feedback

## Цель

Сделать состояние каждой ячейки читаемым непосредственно на поверхности планеты, сохранив ключевой принцип Voronia: планета состоит из ячеек различной геометрической формы, а не из унифицированных шестиугольников.

## Реализация

- `PlanetMeshData.cellStates`: `0 = hidden`, `1 = revealed`, `2 = explored`.
- `boundaryPositions` строится по исходному `GeneratedCell.poly`; каждая сторона конкретного полигона остаётся отдельным сегментом.
- `boundaryColors` различает скрытые, открытые и исследованные контуры.
- Неисследованные клетки получают нейтральную окраску и нейтральный профиль рельефа, чтобы не раскрывать их тип.
- Выбранная клетка сохраняет подсветку; маркер выбора слегка пульсирует.
- Существующие типоспецифичные профили рельефа и радиальное направление роста не заменены общей геометрией.

## Проверки

Добавлены тесты на соответствие числа сегментов сумме `cell.poly.length`, наличие разных количеств сторон в одной планете, корректное кодирование трёх состояний и недоступность hidden-клеток для выбора.

Архитектурный контроль выполняется отдельно. Полный TypeScript/Vitest/build и браузерный WebGL прогон требуют установки зависимостей и остаются отложенными, как договорились.
