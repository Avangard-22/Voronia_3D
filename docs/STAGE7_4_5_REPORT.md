# Stage 7.4.5 — System Navigation & Exploration Interface

## Реализовано

- Добавлен отдельный пункт навигации «Звёздная система» рядом с режимами поверхности и галактики.
- Выбор обнаруженного узла галактики открывает системное представление; в нём отображается каталог звезды, подтверждённая планета и только активированные дополнительные планеты.
- Добавлены явные действия «Открыть систему» и «К галактике» в карточке выбранного узла.
- Возврат к галактике снимает системную орбитальную геометрию и восстанавливает обзор карты.
- Повторный вход пересобирает топологию из актуального доменного состояния, поэтому новые активированные тела появляются в системе.
- Прямой выбор планеты в 3D по-прежнему вызывает доменную команду `travelWithinSystem`; межзвёздный перелёт остаётся отдельной командой `travelToPlanet`.
- После перехода на поверхность интерфейс автоматически возвращается в режим «Поверхность».

## Ограничения

- Неразведанные тела не отображаются как доступные планеты. Их поиск и активация по-прежнему выполняются через карточку системы.
- Это навигационная и исследовательская оболочка, а не физическая модель орбитальной динамики.
- Проверка в браузере/WebGL намеренно отложена по решению пользователя.

## Проверки

- Архитектурный чек — запускается отдельно.
- ZIP/TAR.GZ — проверка целостности после упаковки.
- TypeScript/Vitest/браузер — не заявляются пройденными, если соответствующие инструменты и окружение недоступны.
