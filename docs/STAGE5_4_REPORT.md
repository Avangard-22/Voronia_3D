# Stage 5.4 — развитый рельеф и вертикальный срез планеты

## Реализовано в исходном коде

- Четыре радиальных кольца рельефа формируют несколько уступов вместо одного гладкого склона.
- Профили типов клеток расширены параметрами террасирования и количества надстроек.
- Редкие/кристаллические клетки получают дополнительные трёхгранные кристаллические вершины.
- Аномальные клетки получают асимметричные группы шпилей; исследовательские и ядровые клетки — собственные кластеры.
- Число надстроек увеличивается с уровнем клетки; высота вершины также зависит от уровня.
- Все основания и вершины надстроек строятся в локальном касательном базисе, ориентированном по радиальной нормали планеты.
- Неисследованные клетки сохраняют нейтральный силуэт: типозависимые надстройки создаются только после исследования.
- Все дополнительные треугольники включаются в `faceCellIds`, поэтому выбор поверхности через Raycaster сохраняет cellId.
- Добавлен интеграционный тест сквозного цикла: сканирование → улучшение → рост высоты рельефа и счётчика сессии.

## Игровой цикл одной планеты

В существующем приложении цикл использует реальные команды `Game.dispatch`:

1. Игрок выбирает видимую клетку на поверхности через Raycaster.
2. HUD показывает панель выбранной клетки и допустимое действие.
3. Сканирование меняет `revealed/explored` в домене исследования и начисляет/списывает ресурсы через ledger.
4. Обновление визуальной сигнатуры пересобирает геометрию планеты.
5. Улучшение меняет уровень в `PlanetRuntime`; следующий проход рендера пересобирает рельеф клетки.
6. Сохранение остаётся в существующем SaveManager; визуальные данные не сохраняются отдельно, а детерминированно строятся из состояния игры.

Не заявлять Stage 5.4 как полностью подтверждённый CI-прохождением до запуска `npm ci` и `npm run ci`.

## Ограничения

- Это процедурная геометрия low-poly, а не финальные художественные модели/текстуры.
- Проверка реального WebGL-вида, мобильной производительности и жестов должна выполняться в браузере на целевых устройствах.
- Stage 5.4 не реализует ещё реактор, крафт, транспорт, бой или остальные домены мастер-плана.
