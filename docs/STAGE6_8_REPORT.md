# Stage 6.8 — Galaxy Validation

## Цель

Перед 3D-рендерингом галактики добавить проверяемые доменные инварианты для систем Stage 6.0–6.7. Проверка должна выявлять рассинхронизацию между графом, списком открытых планет, runtime-объектами, маршрутами, грузовой логистикой и сериализуемым состоянием.

## Реализовано

- `src/galaxy/validation.ts` — независимый валидатор структуры галактики и связанных с ней данных.
- `Game.validateIntegrity()` — агрегирует результаты проверки runtime-состояния и `validateSaveV2(collectState())`.
- Проверки списка открытых планет: дубликаты, отсутствующий/необнаруженный узел, отсутствующий runtime, orphan runtime, активная закрытая планета.
- Проверки графа: соответствие ключа `node.id`/`planetId`, конечность координат/частоты, отсутствующие узлы в рёбрах, self-edge и дубли рёбер.
- Проверка связности открытых планет по доступному подграфу: каждый открытый мир должен быть достижим от активной планеты только через открытые обнаруженные узлы.
- Проверка маршрутных путей: начало/конец, число прыжков, nextHop, только открытые узлы, реальные рёбра, конечные неотрицательные дистанции и цены.
- Проверка груза и депо: конечные неотрицательные количества; депо не может принадлежать закрытой/неизвестной планете.
- Сохранена совместимость Stage 6.7: старые сейвы проходят текущую схему при отсутствии необязательной секции logistics.

## Тесты

Добавлен `tests/stage6_8_galaxy_validation.test.ts`:
1. чистое начальное состояние и валидность Save v2;
2. полный цикл: исследование Феррума → открытие Криос-9 → погрузка → перелёт → выгрузка → save/load → повторная проверка;
3. обнаружение dangling edge, duplicate edge и недостижимой открытой планеты;
4. обнаружение отрицательного количества груза и orphan depot.

- `node tools/check_arch.mjs` — PASS (79 файлов; границы слоёв и циклы чисты).
- Strict targeted TypeScript compile (`src/galaxy/validation.ts`, `src/core/game.ts`) — PASS.
- CommonJS compile of Game dependency graph — PASS.
- Node smoke scenario — PASS: начальная проверка; открытие Криос-9; погрузка 10 железа; проверка; перелёт; выгрузка; проверка; сохранение; загрузка; финальная проверка. Все отчёты `ok: true`, без issues.

## Не выполнено / ограничения

- Полный Vitest suite не запускался: зависимости проекта не установлены в рабочем окружении.
- Production Vite build не запускался.
- Не выполнены браузерная проверка, WebGL smoke test и Android-профилирование.
- Валидатор проверяет целостность состояния на момент вызова; он не является серверной защитой от модификации клиента и не заменяет будущую authoritative persistence/anti-cheat архитектуру.
- Текущая экономика Stage 6.7 остаётся частичной: общий ledger и ручная погрузка; автоматическое производство в депо, рынок и флот не входят в этот этап.

## Статус

Код Stage 6.8 внесён, архитектурная/целевая компиляция и Node smoke-проверка пройдены. Полная приёмка проекта не заявляется до выполнения полного CI и браузерной проверки.
