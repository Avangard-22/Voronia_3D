# Stage 6.5 — Anomaly Systems

## Цель
Перевести аномальные сигнатуры из простого фильтра открытия в последовательные игровые экспедиции с реальными условиями, затратами, уникальными наградами и защитой от повторного получения.

## Реализация

### 1. Обнаружение объектов
`src/galaxy/anomalies.ts` строит список аномальных систем только из узлов `GraphNode`, которые уже имеют `discovered: true` и классифицируются как `anomaly`. Неизвестные узлы не раскрывают содержимое.

### 2. Последовательность
Экспедиции сортируются по идентификатору планеты с числовым сравнением. Первая обнаруженная аномалия доступна сразу; каждая следующая становится доступной только после завершения предыдущей. Типы экспедиций: разлом, эхо исчезнувшей системы, сингулярность и живая пустота. Уровень сложности увеличивает стоимость и награду.

### 3. Доменная команда
Добавлена команда `resolveAnomaly`. Она проверяет:
- объект действительно обнаружен и классифицирован как аномальный;
- экспедиция ещё не завершена;
- предыдущая экспедиция завершена;
- активная планета совпадает с планетой аномалии;
- хватает энергии и исследований.

Списание энергии и исследований и начисление `darkMatter`, `relic`, `essence` выполняются одной атомарной транзакцией `ResourceLedger`. Повторная команда отклоняется.

### 4. Сохранение
`SaveGameV2.resolvedAnomalyIds` хранит завершённые аномальные экспедиции. Поле опционально для совместимости с существующими v2-сохранениями; отсутствие поля означает пустой список. Валидатор проверяет, что это массив строк.

### 5. UI
HUD показывает список обнаруженных аномалий, тип/уровень, стоимость, награды и статус цепочки. Кнопка появляется только для доступной экспедиции на активной планете и отключается при недостатке ресурсов.

## Ограничения
- Четыре типа и баланс затрат/наград — первоначальные балансные параметры Stage 6.5, не финально подтверждённые игровым тестированием.
- Это логическая система экспедиций, не отдельная анимационная мини-игра и не 3D-рендерер.
