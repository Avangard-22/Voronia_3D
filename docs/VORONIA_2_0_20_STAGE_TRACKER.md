# Voronia 2.0 — 20 технических контрольных этапов

Это детализация Master Execution Plan на 20 проверяемых поставок. Этап считается закрытым только после кода, тестов, браузерной проверки и фиксации результата. Статус «код внесён» не равен «этап принят».

|---:|---|---|---|

## Ближайшая последовательность

Сначала закрыть №08–10: реальный выбор клетки, рельеф и законченный игровой цикл одной планеты. Только после этого переходить к №11 и расширять галактическую прогрессию. Это уменьшает риск наращивать системы поверх неработающего основного взаимодействия.
