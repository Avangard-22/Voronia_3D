# Этап 9.2 — игровой экран v1 и чистое ядро галактики

**Дата:** 2026-11-03 · **Версия:** `2.0.0-stage9.2.0` · **ADR-020** · **CI:** lint 0, tsc×2 0,
`check:arch` OK (105 файлов), Vitest **64 файла / 398 тестов**, single-бандл 793.22 КБ (gzip 226.23 КБ),
`check:size` 0.76 МБ ≤ 6 МБ.

## Почему

Отзыв владельца по живому сайту (скриншот вида «Галактика»):
1. «зачем в центре ядра столько солнечных систем» — системы узлов графа (радиус ~4–8)
   и фоновые системы с `coreBias` сливались в центре диска радиусом 95 в кашу вокруг
   бледно-серой сферы-декорации;
2. «ячейки на планетах работали также как в версии 1, а не карточками внизу» — HUD
   дублировал все клетки сеткой карточек под сценой;
3. «нужен игровой экран именно таким (или почти таким) как в версии 1… ячейки активные,
   по ним можно кликать делая апгрейд»;
4. «все изменения пока в рамках одной системы — ЦЕНТРАЛЬНАЯ ЗВЕЗДА» (подпись панели
   при этом показывала заглушку Stage 7.3: «ЦЕНТРАЛЬНАЯ ЗВЕЗДА · BLUEBLUE · CRYOVOR-Α-556»).

## Что сделано

### Галактика: центр = одна звезда
| Параметр | Было | Стало |
|---|---|---|
| внутри 0.30·R диска | ядро + системы узлов + фоновые | только `sys:core` (инвариант в `validateStarMap`) |
| системы узлов графа | в координатах узла (r ≈ 4–8) | поселенческое кольцо r ∈ [36.1, 53.2], направление узла сохранено |
| фоновые системы | r от ~8 | r ≥ 28.5 (медиана 56.9, макс 89.7) |
| декор ядра | бледная сфера 0.075·R + синяя сфера 0.26·R + тор | тёплое гало 0.085·R `#ffbf70` + свет `#ffcf9a`; звезда — инстанс каталога (yellow, 5772 K, 1.02 L☉) |
| рукав системы узла | считался на новой позиции (спорил с графом) | каноничный `GraphNode.armId` (Феррум → forge/VOR-Β-561, Криос-9 → frost/VOR-Γ-556) |

Раскладка новой карты: **39 систем, 112 планет**, диск 95. Феррум r=41.5 (171°),
Криос-9 r=43.6 (−17°). Позиции детерминированы и не сдвигаются при открытии миров.

### Панели: каталог вместо заглушки
Карточка системы и подробный вид берут имя/обозначение/звезду из `galaxy/starMap.ts`;
`buildGalaxySystemDetail(node, catalog?)` больше не печатает «BLUE · CRYO».
Подписи классов человекочитаемы (`STAR_CLASS_LABELS`): строка панели читается как
«ЦЕНТРАЛЬНАЯ ЗВЕЗДА ГАЛАКТИКИ · жёлтый карлик / Центральная звезда / VOR-Α-001 · 5772 K · 1.02 L☉ · планет 5». Вкладка «Звёздная система» по умолчанию
открывает центральную систему (`openSystemViewById(coreSystemId)`).

### Поверхность: экран v1
- Сетка карточек `.board` удалена; действия клетки — в плавающем доке поверх canvas
  (`renderCellDock`): выбор клетки кликом по планете → док со сканом/апгрейдом/разрядом/
  реактивацией/ветвями аномалии и кнопкой снятия выделения.
- Наведение: курсор `pointer` + тонкое кольцо (`setHover`, raycast с rAF-троттлингом,
  общий `cellAt` для клика и ховера).
- Звёздное небо: 520 детерминированных точек вокруг планеты (вне `planetGroup`).
- Команды дока идут через существующий `bindCommands` (единая точка входа UI, STAGE1 §4).
