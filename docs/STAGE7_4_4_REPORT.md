# Stage 7.4.4 — Orbital Mechanics & System Readability

## Реализовано
- Доменная топология теперь передаёт в renderer эксцентриситет, наклон и начальную фазу каждой орбиты, а также физический профиль звезды.
- Орбитальные траектории строятся как эллипсы, а не окружности.
- Положение планет рассчитывается через приближённое решение уравнения Кеплера; эксцентриситет влияет на скорость движения по орбите.
- Наклон орбиты учитывается и для траектории, и для положения планеты.
- Цвет центральной звезды зависит от её класса из каталога; материалы планет различаются по типу тела.
- Неизвестные и неактивированные объекты по-прежнему не создаются как доступные планеты.

## Границы этапа
Это визуально-кинематическая модель для игрового представления системы, а не астрофизический симулятор высокой точности. Масштабы орбит условные; столкновения, гравитационные возмущения и многотельная динамика не моделируются.

## Проверки
Проверены статически структура изменений и архитектурный скрипт. Полный TypeScript/Vitest/build и браузер/WebGL отложены по решению пользователя до последующей общей браузерной проверки.
