# Stage 7.4.2 — SYSTEM TOPOLOGY & ORBITAL NAVIGATION

## Реализовано

- `src/galaxy/systemTopology.ts` строит доменную проекцию системы с родительской связью `parentSystemId`, орбитальными индексами и идентификаторами активированных планет.
- Класс неразведанного тела остаётся скрытым (`unknown`).
- `canNavigateWithinSystem` разрешает навигацию только к подтверждённым/активированным телам.
- Добавлена команда `travelWithinSystem`. Она проверяет доступность системы, runtime планеты и принадлежность планеты к активированной орбите этого хозяина. Переход внутри одной системы не списывает межзвёздную энергию и не требует ребра в графе галактики.
- В карточке системы активированные орбитальные планеты получают действие «ПЕРЕЙТИ».
- Родительские связи не дублируются в сейве: они детерминированно восстанавливаются по `orbitalExploration.activatedBodies`.

## Границы

- Орбитальные параметры пока являются детерминированной игровой моделью, а не N-body физикой.
- Не добавлялись спутники и отдельные физические тела, для которых нет генератора/runtime.
- Межзвёздный `travelToPlanet` не менялся; он продолжает использовать граф и существующую стоимость маршрута.
