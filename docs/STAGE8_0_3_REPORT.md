# Stage 8.0.3 — Cell Geometry & Upgrade Deformation

## Цель

Усилить индивидуальную геометрию ячеек Voronia без перехода к унифицированной hex-сетке и обеспечить изменение рельефа при улучшении клетки.

## Реализация

- Сохранена исходная топология `GeneratedCell.poly`: число вершин и контур каждой ячейки не нормализуются.
- Добавлена детерминированная морфологическая вариация на основе ID клетки. Она влияет на асимметрию внутренних склонов/уступов и не зависит от порядка рендера или времени кадра.
- В `PlanetMeshData.cellMorphology` публикуется стабильный вариант морфологии `0..3` для последующих визуальных слоёв/материалов.
- Высота рельефа учитывает тип, уровень и небольшой стабильный коэффициент индивидуальности клетки.
- Уровень влияет также на детализацию террас; кристаллические/аномальные надстройки продолжают использовать локальную радиальную систему координат.
- Внешний контур полигона остаётся на общем базовом радиусе. Деформация применяется к внутреннему рельефу, поэтому upgrade не раздвигает границы соседних ячеек.
- `PlanetMeshData.cellLevels` сообщает фактические уровни, использованные при построении меша.
- Сопоставление `faceIndex → cellId`, состояния hidden/revealed/explored и доменные команды не менялись.

## Проверки

- Добавлены тесты на сохранение разной полигональной топологии, детерминизм морфологии, деформацию после upgrade, неизменность контуров и конечность координат.
- `node tools/check_arch.mjs` — пройдено: 87 файлов, границы доменов чисты.
- ZIP и TAR.GZ — целостность подтверждена.
- TypeScript, Vitest, production build и браузер/WebGL не запускались: зависимости проекта в рабочей среде не установлены. Браузерную проверку, как договорились, откладываем.

## Ограничения

- Текущая деформация строится при пересборке меша после изменения состояния, а не интерполируется во времени. Плавная анимация upgrade — отдельная задача.
- Общая геометрия стыка обеспечивается единым базовым контуром; сложное непрерывное сглаживание между клетками с разной высотой не вводится, чтобы сохранить их геометрическую индивидуальность и не скрывать границы игрового участка.
