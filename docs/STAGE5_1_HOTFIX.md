# Stage 5.1 — HUD / WebGL lifecycle hotfix

## Исправлено

1. `#app` теперь содержит постоянные независимые узлы `#game-scene` и `#game-hud`.
2. `renderSnapshot()` вызывается только для `#game-hud`; его `innerHTML` больше не может удалить WebGL canvas.
3. Делегирование команд UI также привязано к `#game-hud`.
4. Сигнатура исследованных клеток строится по их ID, а не только по количеству. Это обнаруживает замену набора исследованных клеток при загрузке/переключении состояния с тем же размером множества.
5. При `pagehide` очищается HUD-таймер и освобождаются ресурсы Three.js.
6. Версия проекта синхронизирована на `2.0.0-stage5.1`; подпись HUD обновлена.

## Границы исправления

Это hotfix жизненного цикла DOM/WebGL. Он не объявляет завершёнными выбор клетки через Raycaster, визуальную деформацию клетки при улучшении или полноценный Planet Vertical Slice.

## Проверка

Автоматические тесты и сборка должны быть запущены в окружении с установленными npm-зависимостями (`npm ci`, затем `npm run ci`). В исходном окружении на момент подготовки архива `node_modules` отсутствовал, поэтому результат `npm run ci` здесь не заявляется.
