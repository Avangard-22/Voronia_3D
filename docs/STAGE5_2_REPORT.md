# Stage 5.2 — выбор клеток на 3D-поверхности

**Версия:** `2.0.0-stage5.2`  
**Статус:** реализация внесена; автоматическая сборка и браузерная приёмка не подтверждены из-за отсутствующих npm-зависимостей в рабочем окружении.

## Изменения

1. `planetMesh.ts` теперь возвращает `cellIds` и `faceCellIds`. Последний массив связывает каждый треугольник surface mesh с исходным ID клетки; код не предполагает, что ID клетки совпадает с индексом массива.
2. `scene.ts` использует `THREE.Raycaster` по поверхности планеты. Короткое нажатие выбирает клетку; перетаскивание по-прежнему вращает планету. Порог различения click/drag — 6 CSS-пикселей.
3. Выбранная клетка отмечается кольцом, ориентированным по радиальной нормали сферы.
4. `PlanetViewer` получил `selectCell()` и `setCellSelectHandler()`.
5. `main.ts` хранит ID выбранной клетки, синхронизирует маркер с перестроением меша и очищает выбор при смене планеты.
6. `ui/app.ts` показывает панель выбранной клетки с доступными действиями; команды продолжают идти через `Game.dispatch`.
7. Добавлены проверки соответствия `faceCellIds` топологии полигонов и детерминизма новых массивов.
