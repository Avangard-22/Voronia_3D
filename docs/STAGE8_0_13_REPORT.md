# Stage 8.0.13 — Surface Chunking & Asynchronous Geometry Pipeline

## Реализовано

- Добавлен `src/renderer/surfaceChunks.ts`: cooperative async partitioner для существующего triangle-soup меша.
- Треугольники распределяются по 8 пространственным октантам согласно радиальному центру исходной клетки.
- Переносятся все surface vertex attributes (цвет, нормаль, геологические параметры и анимационные атрибуты).
- Для каждого чанка сохраняется локальный массив `faceCellIds`; hit testing переводит `faceIndex` обратно в исходный `cellId`.
- В `scene.ts` первоначальный монолитный меш остаётся видимым и доступным для выбора, пока чанки не подготовлены. После успешной подготовки сцена атомарно заменяет монолит набором чанков.
- При смене планеты/уничтожении сцены старые задачи отменяются токеном поколения. Ошибка оптимизации не ломает исходную поверхность: остаётся fallback-меш.
- Добавлены тесты распределения треугольников, сохранения cell identity/атрибутов и отмены.

## Границы реализации

- Это cooperative asynchronous pipeline на главном потоке с уступкой event loop, не Web Worker и не GPU compute.
- Исходная полная геометрия и массивы mesh data пока остаются в памяти; чанки временно дублируют геометрию на этапе перехода. Выгрузка удалённых данных и стриминг из Worker не реализованы.
- Разбиение по октантам — базовая пространственная партиция, не quadtree/icosphere streaming.
- Геометрия клетки и её исходный полигон не упрощаются. Raycasting по поверхности сохраняет идентификацию клетки через chunk-local face map.
