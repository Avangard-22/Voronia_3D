# Stage 7.0 — Galaxy 3D Renderer

## Цель

Создать первую интерактивную пространственную сцену галактики, которая визуализирует существующий `PlanetaryGraph`, не подменяя игровые узлы декоративными объектами.

## Реализовано

- `src/renderer/galaxyModel.ts` — чистая проекция узлов/рёбер графа в координаты сцены. Координаты X/Y/Z берутся из `GraphNode` и масштабируются единым коэффициентом; процедурные позиции планет не создаются.
- `src/renderer/galaxyScene.ts` — Three.js-сцена: звёздное поле, визуальные спиральные рукава, центральное свечение, `InstancedMesh` для узлов и `LineSegments` для подтверждённых связей.
- Скрытые узлы показаны только как слабые безымянные сигналы; метаданные рукава/сигнатуры/названия скрываются до обнаружения.
- Рёбра отображаются только тогда, когда оба конца обнаружены.
- Открытые планеты имеют отличимый цвет, активная планета выделяется золотым, аномалии/криогенные/энергетические/ресурсные сигналы получают палитру по фактическому классу из snapshot.
- Добавлен переключатель «Планета / Галактика 3D», вращение мышью/касанием, масштабирование колесом и кнопками.
- Выбор открытого узла вызывает существующую доменную команду `travelToPlanet`; закрытые и неизвестные узлы не запускают перелёт.
- Сцена обновляется при игровых командах, а не пересобирается каждый кадр; WebGL-ресурсы освобождаются при закрытии страницы.

## Границы этапа

- Спиральные рукава, звёзды и центральное свечение — фоновые элементы визуализации, а не игровые планеты/ресурсы/узлы.
- На этом этапе не реализованы орбиты отдельных планет, полёты кораблей, туманности высокого качества, выбор маршрута через неизвестные системы, LOD по расстоянию и эффекты аномалий.
- В сцене пока нет подписей для всех узлов: детали мира остаются в существующей панели карты/экспедиции.

## Тестирование

- Добавлены unit-тесты проекции графа: координаты, скрытие метаданных неизвестных узлов, фильтрация рёбер.
- Полный Vitest, Vite production build и браузерный WebGL smoke test должны выполняться в окружении с установленными зависимостями и GPU/WebGL. Если они не запускались, это не считается пройденной проверкой.
