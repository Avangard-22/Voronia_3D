# Stage 5.3 — рельеф и радиальное развитие клеток

**Версия:** `2.0.0-stage5.3`  
**Статус:** код внесён; из-за неполного npm install полный CI и браузерная визуальная приёмка не подтверждены.

## Реализовано

1. Поверхность клетки больше не плоская fan-триангуляция. Каждый полигон разбивается на радиальные полосы с промежуточными кольцами; граница остаётся на базовом радиусе, внутренний рельеф поднимается или опускается относительно центра планеты.
2. Добавлены отдельные профили для типов 0–7: энергетическая впадина, купол, кристалл, гряда, аномальный шпиль, криогенный купол, исследовательская терраса и ядро.
3. Уровень клетки берётся из `PlanetRuntime.cellStates` через `MeshBuildOptions.cellLevels`. Рост ограничен и насыщается через квадратный корень уровня, чтобы не создавать неограниченные пики.
4. Неисследованные клетки получают нейтральный силуэт, чтобы геометрия не раскрывала их тип до исследования. Палитра explored/unexplored сохраняется.
5. Добавлены `cellSurfaceCenters` и `cellHeights`; маркеры и кольцо выбора позиционируются по фактической высоте клетки.
6. `main.ts` отслеживает не только состав explored, но и подпись уровней клеток. После апгрейда перестраивается геометрия планеты.
7. `faceCellIds` синхронизирован с новой треугольной сеткой: каждый треугольник по-прежнему отображается в исходный `cellId` для Raycaster.

## Проверки

- Изолированная строгая проверка TypeScript для `planetMesh.ts` — пройдена.
- Изолированный runtime smoke-test синтетической планеты — пройден: конечные координаты, согласованность face map, увеличение высоты при уровне 16 и радиальная коллинеарность центров.

## Ограничения текущей реализации

- Геометрические профили являются первым процедурным слоем рельефа, а не финальными художественными моделями кристаллов/аномалий.
- Изменение уровня отражается геометрически; анимация постепенного роста и уникальные силуэты на высоких уровнях остаются следующими задачами полировки.
- Stage 5.3 не закрывает Planet Vertical Slice: требуется проверить полный игровой цикл на реальной сборке и на сенсорном устройстве.
