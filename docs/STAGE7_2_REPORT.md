# Stage 7.2 — Galaxy Visual Depth

## Реализовано

- Добавлены процедурные объёмные газопылевые облака из `THREE.Points` с фиксированным seed. Они являются декоративным фоном и не создают игровые узлы.
- Добавлены небольшие звёздные скопления вдоль спиральных рукавов; их координаты также детерминированы и не связаны с `PlanetaryGraph`.
- Добавлено кольцо центральной области галактики.
- Добавлен ближний LOD для обнаруженных звёздных систем: при приближении появляется более чёткое ядро системы. Это визуальная детализация того же узла, а не новая планета.
- Реализованы три режима детализации по дистанции камеры: `wide`, `regional`, `system`. В ближнем режиме скрываются общегалактические рукава, туманности и скопления, чтобы сфокусировать сцену на выбранных системах.
- Бюджет декоративных частиц адаптируется по ширине экрана и DPR: мобильные и высокоплотные экраны получают меньше точек.
- Все реальные системы и игровые рёбра по-прежнему поступают из `PlanetaryGraph`; скрытые системы не получают раскрытых данных.

## Новые файлы

- `src/renderer/galaxyVisualDepth.ts` — чистые правила LOD и бюджетов частиц.
- `tests/stage7_2_galaxy_visual_depth.test.ts` — проверки порогов LOD и адаптивного бюджета.

## Проверки, фактически выполненные

- `node tools/check_arch.mjs` — пройдено: `check_arch: OK (83 файла, слои/циклы/границы доменов чисты)`.
- Строгая компиляция `galaxyVisualDepth.ts` через глобальный TypeScript — пройдена.
- Node smoke-test порогов LOD и адаптивных бюджетов — пройден.
- Синтаксическая транспиляция `galaxyScene.ts` через TypeScript `transpileModule` — пройдена. Это проверка синтаксиса, не полная типизация Three.js API.
- Полный Vitest, production build и реальный WebGL/Android smoke-test не выполнялись.

## Ограничения

- Газопылевые облака и звёздные скопления — процедурная декорация, не игровые объекты и не источники данных.
- LOD пока управляет видимостью крупных декоративных слоёв и ближними ядрами систем; это не полноценная система геометрического LOD для отдельных планет.
- Реальные орбитальные тела и физические звёздные системы не генерируются этим этапом.
