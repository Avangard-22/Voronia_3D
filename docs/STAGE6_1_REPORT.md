# Stage 6.1 — Sonar Expansion

## Реализовано

- Сонарные заряды стали расходуемым ресурсом для открытия процедурных миров после Криос-9.
- Стоимость открытия растёт по индексу планеты: `ceil(hintEnergy * max(1, index - 2)^1.35)`.
- Количество зарядов для открытия растёт ступенчато: `min(chargeMax, 1 + floor((tier - 1) / 4))`.
- Пересборка следующей сигнатуры расходует один сонарный заряд и `ceil(discoveryCost * rerollBurnPct)` энергии.
- Число пересборок ограничено `rerollMax`.
- Пересборка меняет только будущую сигнатуру. Уже открытые планеты не затрагиваются.
- Seed следующей планеты теперь принудительно берётся из серверного preview; переданный UI seed не может подменить генерацию.
- Счётчик пересборок сохраняется и восстанавливается. Счётчик зарядов сохраняет прежний cap.
- UI показывает стоимость открытия, стоимость пересборки, зарядную потребность и оставшийся лимит пересборок.

## Тесты добавлены

`tests/stage6_1_sonar_expansion.test.ts` покрывает:
- блокировку открытия без зарядов;
- списание энергии и зарядов при открытии;
- изменение seed при пересборке;
- сохранение и восстановление счётчика пересборок;
- лимит пересборок;
- cap и persistence сонарных зарядов.

## Баланс / допущения

Стоимость открытия после Криос-9 использует `hintEnergy` как базу и растёт по формуле индекса; стоимость пересборки — доля `rerollBurnPct` от цены открытия. Это конкретное Stage 6.1 правило поверх существующего registry, а не утверждение о подтверждённом паритете с исходным монолитом.
