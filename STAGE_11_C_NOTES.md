# Voronia 3D — Stage 11 C: Modal Architecture + Reactor v39

Эта сборка содержит полный исходный проект `Voronia_3D` с интегрированными изменениями Stage C.

## Состав Stage C

- общий модальный каркас: закрытие по Esc и backdrop, возврат фокуса, блокировка прокрутки страницы, focus trap;
- адаптивный интерфейс модального окна для мобильных экранов;
- отдельные окна Reactor v39, Storage (6 страниц), Sonar, Galaxy Map, Tech Tree, Research, Statistics, Help, Offline Report, Save/Load, Settings и About;
- реактор с фокусом на одном рецепте, переключением рецептов, выбором ×1/×10/×25, очередью и прогрессом;
- покупка дополнительных слотов реактора с атомарной транзакцией и сохранением в сейве;
- регрессионные тесты покупки и сериализации слотов.

## Известные границы функциональности

- Развёрнутый отчёт офлайн-начислений не подключён к `GameSnapshot`; окно честно сообщает об ограничении.
- Назначение ролей планет пока не связано с доменной моделью; вкладка обозначает незавершённую функцию.
- Покупка слота в текущей реализации списывается через V2 global ledger. Это не считается подтверждённым паритетом с V1 `spendAny` по складам нескольких планет.
- Визуальная и поведенческая проверка в браузере и на мобильном устройстве не выполнена.
