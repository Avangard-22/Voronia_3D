# Как заменить исходники Voronia 3D этой сборкой

1. Сделай резервную копию текущего репозитория и текущих сохранений игры.
2. Распакуй ZIP.
3. Открой вложенную папку `Voronia_3D_Full_Stage_C`.
4. Скопируй **всё её содержимое** в рабочую папку репозитория `Voronia_3D`, соглашаясь на замену файлов. Папку `.git` из локального клона не удаляй.
5. В корне проекта выполни:

```bash
npm ci
npm run ci
```

6. Только если обе команды завершились успешно, отправляй изменения в GitHub и проверяй GitHub Actions.

ZIP содержит полный исходный проект, конфигурацию GitHub Actions, документацию, фикстуры и Stage C. `node_modules` намеренно не включён. Не загружай архив как вложенную папку в репозиторий: копировать нужно именно содержимое папки `Voronia_3D_Full_Stage_C`.

Основа: commit `18db5a81d9b16ad19a565b882090e3945e0fde8d` + исходники Stage C. Текущий архив прошёл синтаксическую проверку TypeScript и проверку JSON, но полный `npm run ci` в среде подготовки не был завершён из-за тайм-аута npm registry. Поэтому сначала проверь команды локально и не удаляй резервную копию текущей версии до успешного CI.
