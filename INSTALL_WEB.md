## Способ А — одна загрузка из корня репозитория (рекомендуется)

GitHub умеет сам воссоздавать пути: если перетащить папки из корня пакета на страницу
загрузки **корня репозитория**, файлы лягут куда нужно, одноимённые заменятся, новые создадутся.

1. Скачайте `web-bundle-stage9.3.zip` (рядом с этой инструкцией) и распакуйте.
   Внутри папки `web-bundle-stage9.3/` вы увидите: `src/`, `tests/`, `docs/`,
   `README.md`, `package.json` (и эту инструкцию).
2. Откройте корень репозитория: <https://github.com/Avangard-22/Voronia_3D>
   (вы должны видеть папки `src`, `tests`, `docs`, файлы `README.md`, `package.json`).
3. Нажмите **Add file → Upload files**.
4. Из распакованной папки перетащите в зону загрузки **пять элементов верхнего уровня**:
   `src`, `tests`, `docs`, `README.md`, `package.json`.
   - ⚠️ Перетаскивайте именно из корня распакованного пакета. Страница загрузки —
     именно корень репозитория (URL без `/tree/main/src/...`). Иначе получится
     вложенность `tests/tests/` (так уже бывало).
5. Дождитесь появления списка (~37 файлов с путями вида `src/core/game.ts`).
   `INSTALL_WEB.md` можно исключить из загрузки (крестиком) или оставить — не страшно.
6. Внизу нажмите **Commit changes** (Commit directly to the main branch).
7. Через 1–2 мин отработает Deploy workflow; сайт обновится:
   <https://avangard-22.github.io/Voronia_3D/>

4. Старый сейв: при импорте legacy-сохранения эпохальные кулдауны («⏳ 1700000000 с»)
   обнуляются — клетки без гигантских таймеров.

## Что нового в игре (Этап 9.3)

- **Технологии:** дерево исследований (цены v1 + граф требований); эффекты реально
  влияют на игру: доход железа/кристаллов/криогена (+25%/ур.), кулдаун жил (−10%/ур.),
  доход жил (+20%/ур.), цена скана (−5%/ур.), потолок уровня клетки (+1/ур.),
  открытие ресурсов и рецептов.
- **Реактор:** 11 рецептов v1 (сталь → чип → сплав → ядро → реликт; блоки данных;
  гелий-3/биомасса/платина). Очередь до 50 задач, входы списываются атомарно на старте
  прогона, при нехватке ресурсов прогон встаёт в «Дефицит» без потери прогресса,
  отмена снимает не стартовавшие прогоны. Очередь и прогресс сохраняются в сейве.
